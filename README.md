# NucGuessr ☢️

Jeu par navigateur au format défi quotidien : reconnaître une centrale nucléaire française (puis, plus tard, d'autres sites nucléaires) à partir d'une photo.

Projet étudiant (promo d'ingénierie nucléaire, ENSTA), sans lien avec EDF, Orano, le CEA ou l'ASNR.
